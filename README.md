# 건강일기 · 대사 코치

개인용 다이어트 기록 웹앱의 프론트엔드입니다. 백엔드(Google Apps Script + 구글시트 + Gemini)는 이 저장소에 포함하지 않습니다.

- 모든 요청은 구글 로그인 ID 토큰을 백엔드에서 검증하며, 등록된 계정 한 개만 접근할 수 있습니다.
- API 키 등 비밀값은 프론트엔드에 없습니다.
- `js/config.js`의 `GAS_URL`을 비우면 브라우저 안에서만 동작하는 미리보기 모드로 실행됩니다.

## 칼로리 플랜 계산

- 기초대사량: 체지방률이 있으면 Katch-McArdle(`370 + 21.6 × 제지방량`), 없으면 Mifflin-St Jeor(여성)
- 유지 칼로리 = 기초대사량 × 활동량 계수
- 하루 감량 칼로리 = (현재 체중 − 목표 체중) × 7,700 ÷ 남은 일수
- 안전장치: 섭취량은 기초대사량·1,200kcal 아래로 내리지 않고, 주당 감량은 체중의 1%를 넘지 않음
